# Estrutura-de-Dados---Logistica-Urbana-e-Gerenciamento-de-Pedidos
Projeto de estrutura de dados que busca avaliar o conhecimento e habilidades dos membros do grupo nos tópicos trabalhados no semestre de Estrutura de dados

**Requisitos Funcionais** 

****Módulo 1	Cadastro e Consulta de Pontos de entrega**
 	
RF01	Cadastrar Ponto de entrega
RF02	Buscar Ponto de Entrega
RF03	Listar pontos de Entrega
RF03.1	Excluir ponto de entrega
	**
**Módulo 2	Gerenciamento de Pedidos (Heap / Fila de Prioridade)**
	
RF04 	Inserir Pedido
RF05	Consultar próximo pedido
RF06	Processar despacho
RF07	Exibir Pedidos Pendentes

****Módulo 3	Histórico de Operações ( Lista Encadeada ou Vetor Dinâmico)**
	
RF08	Registrar pedido processado
RF09	Consultar histórico
RF10	Consultar pedido no histórico

**Módulo 4	Relatórios, Carga de Dados e Ordenação**
	
RF11	Gerar relatório ordenado
RF12	Comparar algoritmos
RF13	Carga inicial automatizada
